# HOMEX Deploy

Repositorio de infraestructura y despliegue del Sistema de Gestión de Pedidos HOMEX.

## Repositorios relacionados

- `homex-frontend`
- `homex-backend`
- `homex-nlp`
- `homex-deploy`

## Responsabilidad

Este repositorio centraliza la configuración necesaria para desplegar los componentes de HOMEX.

Inicialmente contemplará:

- Docker Compose
- PostgreSQL
- Backend
- Frontend
- Servicio NLP
- Redes Docker
- Volúmenes
- Variables de entorno
- Reverse proxy
- Scripts de despliegue
- Configuración de producción
